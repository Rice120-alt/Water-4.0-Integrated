# Local artwork input boundary

The production overlay embeds game-derived item portraits, a Water Broker
shopkeeper portrait, and a water icon. Those visual inputs are not redistributed
in this source disclosure. To reproduce the production artwork locally, place
the corresponding files from a legitimate game installation or an authorized
working copy under this folder and add them to the disclosure project as
`EmbeddedResource` entries. The source uses text/fallback rendering when an
asset is absent.
